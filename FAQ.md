# Frequently asked questions

[← Allora Dashboard](README.md)

## Can I download and run the bot from this repository?

No runnable application is distributed here. This repository contains explanatory documents and a schematic illustration. It has no bot source, dependency manifests, deployment scripts or private service configuration.

## Is this an open-source release?

No. Public documentation does not make the private implementation open source or grant access to it. No application source license is provided by this showcase.

## Can I try a live demo or invite the bot?

This repository does not promise a public demo, invitation or hosted access. Ask the project owner about availability.

## Does every deployment copy the private repository here?

No. Only explicitly selected public documents and a generated update marker can be published. Commit messages from private development and internal issue details are not copied. Documentation changes require deliberate editing of the public materials.

## Are the pictures real community data?

The included image is an illustrative layout, not a live screenshot. It contains no real members, messages or community records.

## Does an update marker prove everything is healthy?

No. It records completion of the deployment checks used by the publisher. It is not an uptime monitor or a guarantee that every third-party integration is working.
