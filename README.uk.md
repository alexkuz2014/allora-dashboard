# Allora Dashboard

**[English](README.md) · [Русский](README.ru.md) · Українська**

Allora поєднує Discord-бота, вебпанель і допоміжні сервіси для керування спільнотою. Учасники й адміністратори отримують різні інструменти відповідно до своїх прав.

Це публічний опис продукту. Вихідний код застосунку й робочі налаштування зберігаються приватно. Тут немає готового бота, пакета для самостійного розгортання чи виконуваної вебпанелі.

## Можливості

| Розділ | Призначення |
|---|---|
| Огляд спільноти | Активність та основні інструменти в одній панелі. |
| Учасники | Профілі, відомості про учасників і записи активності. |
| Модерація | Попередження, відпрацювання та процеси перевірки. |
| Заявки й контракти | Налаштування форм подання та розгляду. |
| Активність і нагороди | Бали, досягнення, завдання та реферали. |
| Економіка | Магазин, покупки, кейси й інвентар. |
| Події | Звіти, участь і процеси нарахування нагород. |
| Розклад | Таймери, нагадування та заплановані публікації. |
| Музика | Пошук і керування відтворенням у голосових каналах. |
| ШІ-помічник | Допомога учасникам і дозволені інструменти адміністрування. |
| Telegram | Підтримувані оновлення Telegram у процесах спільноти. |
| Адміністрування | Налаштування функцій, ролей та інтеграцій. |

Доступність залежить від налаштувань спільноти, прав і зовнішніх сервісів. Перелік описує можливості проєкту, а не гарантує ввімкнення всіх функцій у кожній спільноті.

## Інтерфейс

- Окремі представлення учасника й адміністратора.
- Світла й темна теми, адаптація до комп’ютерів і телефонів.
- Форми, списки та стани операцій для повсякденних завдань.
- Постійна робота над доступністю, адаптивністю та надійністю інтерфейсу.

Зображення вгорі — схематична ілюстрація, а не знімок діючої спільноти. Реальних даних учасників у ньому немає.

## Архітектура

Приватна реалізація використовує TypeScript, React, Fastify, Discord.js, PostgreSQL, Redis та Docker. Інтерфейс, API, бот і фонові завдання мають окремі обов’язки. Докладніше: [огляд архітектури, EN](ARCHITECTURE.md).

## Оновлення й доступ

Вітрина отримує лише підготовлені публічні матеріали та позначку оновлення після розгортання. Код, приватна історія комітів, внутрішні плани, журнали й секрети сюди не копіюються. [Останні оновлення](UPDATES.md).

Пріоритети: зрозуміла навігація, мобільні екрани, доступність і надійність. Позначка оновлення не гарантує доступність усіх зовнішніх сервісів.

Запитання можна адресувати [автору проєкту](https://github.com/alexkuz2014). Не публікуйте токени й особисті дані. Умови ознайомлення: [FAQ, EN](FAQ.md).
